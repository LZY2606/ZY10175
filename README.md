# 焊程见证台

工艺资格覆盖与变量限值核查台：核对一份生产工艺是否被现有焊接工艺试验（资格）记录完整覆盖。

## 运行

```bash
corepack pnpm install --frozen-lockfile
corepack pnpm test -- --run          # 自动化测试（引擎 + API）
corepack pnpm dev --host 127.0.0.1 --port 5515
# 打开 http://127.0.0.1:5515 ，页面标题为「焊程见证台」
```

## 数据口径

- **规则包**（`rules/*.json`，版本化）：用受限条件表达式声明必要变量、区间扩展与联合证明组。
  表达式只支持数字、标识符、四则运算、比较（`< <= > >= == !=`）与逻辑（`&& || !`），
  由 `src/shared/expr.ts` 的递归下降解析器求值，**不执行任意代码**。
  - 厚度：闭区间扩展（v1.0.0 为 `[0.5t, 2t]`；v1.1.0 收紧为 `[0.5t, 1.5t)`）。
  - 热输入：半开区间扩展（如 `(0.8h, 1.25h]`），恰好在界限上的工艺按规则声明的开闭判定。
  - 联合证明组「厚度×热输入」：两个变量必须由**同一试件**证明，不允许跨试件拼接。
  - 仅 `splice.allowedVariables` 列出的集合变量（焊接位置、力学检验）允许跨试件拼接。
- **资格记录**（`fixtures/records.json`）：每个试件的**标称值与实测值分开存储**，
  合格区间由实测值按规则扩展计算。过期、撤销或单位不明的记录/变量不参与判定，
  并在「未参与判定的记录」中列明原因。
- **生产工艺**（`fixtures/production.json`，页面可改）：各生产变量的目标值。
- **结论**：每次核查/对比的结论都固定规则包摘要（规则包规范化 JSON 的 SHA-256），
  随运行记录写入 SQLite（`data/witness.db`）。

## 验收场景（固定 fixture）

默认工艺 `WPS-DEMO-18`（厚度 18mm、热输入 1.9 kJ/mm）：

- 厚度 18 仅被 `PQR-2024-001-T1`（区间 `[6, 24]`）单项覆盖；
- 热输入 1.9 仅被 `PQR-2024-002-T1`（区间 `(1.6, 2.2)`）单项覆盖；
- 联合证明组要求同一试件，系统**拒绝拼接**，结论为「未完整覆盖」；
- 缺口行指出最接近的试验 `PQR-2024-001-T1`（热输入差 0.4 kJ/mm）及仍缺证据；
- `PQR-2021-007`（过期）、`PQR-2019-011`（撤销）、`PQR-2024-009`（厚度单位不明）均被排除。

## 重放与复核

- **导出运行记录**：页面按钮或 `GET /api/export`，下载全部核查/对比记录（含输入、结论、规则包摘要）。
- **清空重导**：页面「清空并重导 fixture」或 `POST /api/reset`，清空 SQLite 后从
  `rules/` 与 `fixtures/` 重新导入，可复核出与导出记录一致的结论与摘要。
- **版本对比**：选择「对比版本」后点击「对比两版规则」，逐变量列出两版的覆盖状态与合格区间变化。

## API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/state` | 规则版本（含摘要）、资格记录、默认工艺、最近运行 |
| POST | `/api/check` | 按指定规则版本核查生产工艺，记录运行 |
| POST | `/api/compare` | 两个规则版本的逐变量差异 |
| GET | `/api/intervals?version=` | 各数值变量的试件合格区间（Canvas 图数据） |
| GET | `/api/export` | 导出全部运行记录 JSON |
| POST | `/api/reset` | 清空数据库并重新导入 fixture |

## 结构

```
rules/            规则包 v1.0.0 / v1.1.0（JSON，受限表达式）
fixtures/         资格记录与默认生产工艺
src/shared/       类型、表达式求值器、区间与覆盖判定引擎（前后端共用）
src/server/       SQLite 数据层（node:sqlite）、fixture 导入、HTTP 服务
src/web/          操作页面（原生 JS + Canvas 区间图）
tests/            vitest：验收场景、界限判定、排除规则、版本对比、API 与重放
```
